# Map Layers Management App

Интерфейс управления картографическими слоями на React 19 + TypeScript с использованием Vedro для управления состоянием.

## 🏗️ Архитектура решения

### Обзор архитектуры

Приложение построено на принципах **масштабируемости**, **производительности** и **надёжности**:

#### 1. **State Management - Vedro**

- Централизованное хранилище состояния с `Record<LayerType, LayerState>` для O(1) доступа
- Immutable updates для предсказуемости
- Точечные селекторы для минимизации ре-рендеров

#### 2. **Обработка асинхронности и Race Conditions**

- `Map<LayerType, AbortController>` для независимого управления запросами каждого слоя
- Отмена устаревших запросов при быстром переключении
- Проверка актуальности перед обновлением state

#### 3. **Оптимизация рендеринга**

- `React.memo` для изоляции компонентов
- Точечные подписки: `useSelector((state) => state.layers[layerId])`
- Независимые ре-рендеры: изменение слоя A не влияет на слой B

#### 4. **Масштабируемость O(1)**

- Все операции имеют константную сложность
- Архитектура готова к 50+ слоям без изменений
- До 200+ слоев с минимальными доработками (виртуализация)
- Интерактивная демонстрация производительности на `/scalability`

### Ключевые паттерны

**1. Избежание race conditions:**

```typescript
// Каждый слой имеет свой AbortController
const activeRequests = new Map<LayerType, AbortController>();

// Отменяем предыдущий запрос перед новым
const existing = activeRequests.get(layerId);
existing?.abort();

// Проверяем актуальность перед обновлением
if (activeRequests.get(layerId) === controller) {
	store.dispatch(/* ... */);
}
```

**2. Оптимизация производительности:**

```typescript
// Точечная подписка
const layer = useSelector((state) => state.layers[layerId]);

// Изоляция компонента
export default memo(LayerControl);
```

**3. Строгая типизация:**

- Все типы явно определены без `any`
- Type-only imports для чистоты
- Union types для LayerType

## Функциональность

Приложение позволяет управлять тремя картографическими слоями:

- Температура
- Ветер
- Инсоляция

Для каждого слоя доступны:

- ✅ Включение/выключение слоя
- 🎚️ Регулировка прозрачности (opacity от 0% до 100%)
- 📊 Отображение статуса: idle / loading / success / error
- 🔄 Повторная загрузка после ошибки
- 🔌 Имитация API запроса с возможностью ошибки (20% вероятность)
